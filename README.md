# 🧾 売上管理ダッシュボード

売上データの登録・検索・集計・可視化ができる業務改善ツールです。  
事務業務でよくある「データ入力 → 集計 → 可視化」までを一貫して行えるように設計しました。

## ✨ 主な機能

### ■ データ管理（CRUD）
- 売上データの登録
- 売上データの編集（Update）
- 売上データの削除
- 全データ削除

### ■ 検索・絞り込み・並び替え
- 商品名によるリアルタイム検索
- カテゴリ絞り込み
- 日付・金額での並び替え（昇順 / 降順）
- 全件リセット

### ■ 集計機能
- 登録件数
- 総売上
- 平均売上

### ■ 可視化（Chart.js）
- 日別売上（折れ線グラフ）
- カテゴリ別売上（棒グラフ）

### ■ データ操作
- CSV出力（表示中データ）
- サンプルデータ投入
- localStorageによるデータ保存

### ■ UX改善
- 今日の日付の自動入力
- 登録・更新時のメッセージ表示
- データなし表示
- 編集モード切り替え（登録 ⇄ 更新）
